## New

- **Copy Network URL** in the tray menu, for OBS on a second PC. It appears when `bind_address` lets other devices connect, and copies the overlay address with this PC's network address.
- **"Already running" message.** Starting the app while it's already running now says so (and which version is running, if it's different) instead of closing silently.
- **Keyboard access in the Theme Gallery.** Tab to a preview and press Enter to enlarge it.

## Fixes

- The "cover" tag sometimes didn't appear in the gallery.
- The enlarged view no longer opens with the star focused, so pressing Enter won't star a theme by accident.
- The README covers everything added in 0.2.0, with new screenshots.
