## Fixes

- **A port or network change can no longer close the app.** The Settings page now checks a new port or address before saving it, and refuses one that's already used by another program, reserved by Windows, or blocked by browsers (like 6000). **Restart** checks `config.toml` first too, from the Settings page or the tray menu, so a bad value typed into the file shows a message instead of closing Now Playing.
- **Theme links work in any capitalization again.** In 0.3.0, `?theme=halloween` or `?theme=NEON` loaded no theme at all. Links to the gallery's enlarged view, like `gallery.html#halloween`, also work now, including when you change the address in an open gallery tab.
- **Themes sort alphabetically** in the gallery's favorites and the tray menu, whatever their capitalization.
- **Overlays wait for their theme.** If an overlay loads while Now Playing is restarting (for example when OBS refreshes a source), it now waits and then shows its theme, instead of staying unstyled until you refresh it.
- **No more placeholder text.** Overlays no longer briefly show the words "Title", "Artist", and "Album" while loading.
- **The blurred background clears** in themes like Blurred and CP2077 Billboard when the next song has no cover, instead of showing the previous song's art.

## Settings Page

- **Moving several equalizer sliders quickly saves all of them.** Before, only the last one was saved, even though the others looked changed.
- **The Settings page notices edits to `config.toml`** made in another program, and shows the new port and network choice, the **Restart Now** button, and any errors without a reload.
- A clearer message when ceiling is set below the floor, and "Saved" now disappears after a couple of seconds.
