## Fixes

- **The first song after Apple Music starts now shows its cover.** Apple Music briefly sends a placeholder image when it opens, and Now Playing kept that placeholder for the whole first song. It now switches to the real cover as soon as Apple Music provides it, usually within a few seconds.

## Theme Gallery

- **Copy URL no longer gets stuck on "Copied!"** when clicked twice quickly.
- **Copy URL works in the enlarged view on other devices.** Opening the gallery from a phone or second PC used to show "Copied!" without copying anything. It now copies, or says "Couldn't copy" and selects the address so you can copy it yourself.
- **Search by the name shown on the card.** Searching "radio tuner" now finds Radio Tuner. Before, only the file name (radio-tuner) worked.
- **A message when nothing matches** your search or filters, instead of a blank page.

## Behind the scenes

- **Releases are now checked with automated tests** before they're published, and compared with the previous version, so fixed problems stay fixed.
