## Theme Gallery

- **Click a preview to enlarge it.** See the theme bigger, with its URL, Open and Copy URL, a star, and the background swatches.
- **OBS size on every theme.** Each card shows the width × height to use for the OBS browser source, including any room the theme needs for glows.
- **Scale control.** Pick 1x, 1.5x, or 2x in the enlarged view; the URL and size update to match.
- **Replay popup.** Popup themes have a button to replay their entrance in the enlarged view.
- **Link straight to a theme** with `gallery.html#name`. The browser's Back button closes the enlarged view.
- Cards lift on hover, and previews show an "Enlarge" hint.
- Previews load and size themselves faster, and use less CPU with many cards on screen.

## Tray Menu

- **Left-click on the tray icon** to open the Theme Gallery. Right-click still shows the menu.
- **Version** shows which version you're running; click it to see the releases page.
- **Open Log** opens `nowplaying.log`, handy for bug reports.
